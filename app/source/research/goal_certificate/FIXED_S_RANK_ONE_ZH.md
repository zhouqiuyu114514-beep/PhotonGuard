# 固定 s 秩一侧车与共享迹提议：2026-10-10

本轮把外部技术审稿已经给出的固定参数结论接入独立算术检查器，并执行两份预登记的全局相容试场提议。它没有完成实际返回记录的连续根认证。原生产状态仍为 `TARGET_MODE_RANK_UNBOUND / INCONCLUSIVE / NOT_EVALUATED`。

## 算术侧车的证明范围

`fixed_s_rank_one.py` 对原模型、共同 DOF、三维 M/N/G 区间及先前已验上计数记录做字节绑定。它在原高端形式上以 Fraction 重组

`R=(1+2cτ)N−cG−(τ+cτ²)M, τ=1/20, c=1/(1277/1000−τ)`，

取原列 `[1,2]`。复矩形区间的模上界由整数平方根向外包围，Gershgorin 两行下裕量约为 0.0008250899966162983 和 0.016836612145179418。另重放原三维正见证。结合字节绑定的旧上计数，可得固定 `s=209/100`：

`f2 < 1277/1000 < 32/25 <= f3 < 1/binary64(.775) <= f4`。

所以 `[32/25,1/binary64(.775))` 的谱投影秩为一。左闭端不能擅改为开端。对经检查的实移位 ρ，补谱距离下界为

`min(ρ−1277/1000, 1/binary64(.775)−ρ, |ρ|)`。

仅正下界有效；零核和负谱仍在补谱中。ρ=1283/1000 时下界为 3/500。它不是根管全区间的间隙，也不是原返回根身份绑定。

来源形式的相容性、连续算子域和向外空间积分仍继承上游证明；来源上计数的正确性也继承其已验记录。本轮的哈希核对不等于重新证明这些上游事实。新侧车未做空间组装或特征求解。

## 条件筛选与误差预算

`selector_cone_bounds.py` 使用到失败锥面的相对距离。对正交投影比 p 和阈值 t：

- p>t 时，下降至失败锥的距离是 `sqrt(p(1−t))−sqrt((1−p)t)`；
- p<t 时，上升至失败锥的距离是 `sqrt(t(1−p))−sqrt((1−t)p)`。

证明可在投影及其正交补形成的二维平面中完成：分量相位对齐，对锥面方向上的幅度极小化，所得为夹角正弦。相对扰动 δ<1 能引起的方向角至多 arcsin δ，得到显式比例包围；角度能达到零分量或满分量时，分别饱和到 0 或 1。实现使用区间最坏端点，保留生产阈值 `.55/.35/.05` 的精确 binary64 有理值和严格不等号。

正对角分片 ε 下，用 `γ² >= mean_epsilon_upper / epsilon_min` 检查从电场能量范数到未加权 L2 的转换。没有严格积分提供的 p/core/outer/mean ε 和场误差，就只返回条件命题。

`projector_budget.py` 验算归一全场、秩一投影、`q=r/g<=139/1000`、电场范数 `>=7/10` 时：

`eta <= sqrt(2−2sqrt(1−q²)); e <= eta/(7/10) <= 0.19905510397642462 < 1/5`。

输入有效性用显式拒绝处理；研究包本身继续禁止 `-O/-OO` 绕过旧数学检查。新增测试覆盖最近点达等、严格阈值、宽区间、角度饱和、非对角材料和不足的 γ。

## 两份全局共享迹提议

冻结源码 `f33edddc36ff11c66c8c830d03a6276828913389`。实际 r20 网格为 12800 个三角形、19200 条周期边、6400 个周期顶点，E/H 合计 179200 个复自由度。横向使用 Nédélec 第一族 k=1：每条边两个切向矩、每单元两个内部矩；纵向为 P2。参考矩的对偶系数由 Fraction 精确求得，均为整数。偶切向矩在反向时变号，奇切向矩不变；协变 Piola 映射与周期共有自由度保证共享迹，允许法向跳跃。

次数、矩与映射采用 [DefElement 的 Nédélec 第一族定义](https://defelement.org/elements/nedelec1.html)。本实现自行校准均匀平面波、低次多项式及 curl、边反向、所有周期共享切向/纵向迹和原材料界面。

提议从已存同 k 的历史 band3 E/H 原数组按其坐标周期双线性重构，再插入全局自由度。该历史复现场与原生产返回数组分开绑定，不能替代原记录距离证明。

每份提议一次组装局部连续 M/N/G；3 次 Rayleigh 外层各最多 600 次对角缩放投影 CG，约束为固定锚场的 M 内积等于 1。局部 28×28 形式作矩阵自由乘法，未构建全局稠密正常矩阵，也未调用稀疏 LU。独立 4×4 Duffy 浮点积分直接计算连续分片算子残差。用于优化的 3×3 积分和独立验收积分分别记录。区域量仅为浮点诊断，不视为严格切分积分。

最佳残差约为旧基准的十分之一，但仍高于本移位下的目标 `g*.139 ≈ .00088619`。全部 6 次内层求解均返回迭代上限，而非收敛成功；没有记录可用来证明最小残差已经达到。因此本轮既不能认证场误差，也不能证明该空间不可能过关。后续必须先区分迭代不足与离散空间误差。
