# 独立多层膜需求入口 v2

底层仍使用原film1d-v1配方与固定策略，最多8层、总厚度5微米，正入射线性Ex、无损非色散各向同性、空气两端。旧单膜映射、任务哈希和旧锁保持原义。

新版入口需要独立需求明确+z入射、从入射侧到出射侧的层序、1Meep单位=1微米、每层折射率/厚度/出处及等波长采样。仅有待检脚本不能作为需求出处。未知、冲突或缺少来源保存暂停，不补常用参数、不重排真实层序。

JSON层列表标记 `schema: film_stack_task_v2`，需要case_id、incident_direction、layer_order、units_um、完整physics（另含linear和field_component）、layers、wavelength_um、nfreq、sampling、source。每层包含n、thickness_um、source。

自然语言仅识别明确限定写法，例如“第1层：折射率为1.45，厚度为213 nm，出处为独立任务书第一层。”，层号须连续，另明确物理假设、层数、尺度、场方向及采样。没有宣称理解任意层列表自然语言；不支持的写法需补资料。

在原三步页面保存独立需求，离线核对有序层列表后一次确认，再只读解析脚本并后台检查。规则与模型诊断复用相同流程；真实多层AI诊断尚须单独验证。界面多层放行仅接受新版独立映射及重新投影一致性，不解除旧单膜转换限制。

开发验证使用公开三层和有限四周期八层DBR；后者不保证高反射设计指标。每个修复/正常记录保留完整层序、真实频点、参考配对、固定容差和规范化配方范围。所有开发批准标SIMULATED，不代表真实用户验收。

规则诊断若在数值求解已完成后因源码未冻结等原因停止，可以显式恢复原证据审阅；不会重复求解或派发模型。新修复卡仍要当前批准。旧失败记录保持原样。
