# RC7 已知限制

- 新宽距/高斯反演是有限局部搜索，不证明全局唯一；剖面保留失败点、分离片段和网格分辨率，不给未经校准的 95% 区间。直径与半径转换必须明确；不做自由 M² 计量。
- 补采评分只用已保存候选与局部灵敏度，不读取未来数据或隐藏对象。宽范围可能改善缝宽却降低固定点数下的缝距精度；候选不足时明确降为局部建议或固定基础方案。RC5 24 组研究保留负结果，RC6 四例只加基础菜单仍选 medium，不证明推荐普遍最优或 AI 优势。RC7 保守规则不是严格保证不劣，三种公开假设不能代表所有真实曝光和噪声。
- 新联合任务最多三份 CSV，初始与补采在同一根任务累计预算。只有明确配准才共享中心，每次亮度与背景独立；旧交错留出不是独立采集验证。不同固定波长/焦距的扫描当前不联合，需分别研究。
- 独立冻结教学对象不读取拟合参数，仍与分析共享理想物理模型，未连接真实仪器。单膜已支持已知实折射率、法向入射、无损单层的厚度分析和允许波长目录内补测；单波长周期/对称歧义保留，不估计折射率、吸收、增益或任意多层，T=1-R 不算独立第二观测。
- 观测适用性只支持声明方式和有来源的已知强度平均核。低残差不能排除平均效应；单频局部包络可与自由幅度/背景混淆。这里的强度核不是通用相干像差模型，也没有自由识别 PSF。
- 等数据组均方误差下的局部尺度不是独立采样 Fisher 方差或置信区间。独立噪声协议要求明确标准差、独立性和采集 ID；稳健损失的规划仍是声明尺度下的线性代理。未知实测噪声不能由数值 scale 自动替代。
- 无 UI 复用例子是公开教学任务，不是隐藏评测；固定种子重放不是新独立观测。每个离线目录单独累计额度，不续接或重置生产根预算；Linux/WSL 工作进程有资源限制，尚不承诺原生 Windows 求解。

- 自然语言入口仅整理列明字段，来源检查保守；不支持的表达会保留旧条件并提示使用明确原话或高级表单，不承诺通用语义理解。解释为模型选择焦点、程序填入当前数字与限定语，不是自由诊断仪器根因。
- 唯一数值配置配方只用预设训练点生成初始建议，不是最佳超参数搜索。默认平移范围为训练扫描中点附近的跨度 10%，超出此假设可能碰边界，需要用户核对；不能据此声称标定光轴。

- 旧已知缝宽数据入口支持等宽、相位 0 双缝、理想透镜傅里叶焦平面的 1D 相对强度。固定波长/焦距/缝宽，仅估计缝距与三个观测干扰参数；不反演照片、近场、像差或任意仪器。RC5 的新入口另有公开模型与预算，不覆盖旧协议。
- 噪声样例为合成教学数据；不同数值实现仍共享理想物理模型。局部诊断、多起点与留出残差不证明全局唯一，不输出精确置信区间。MODEL_ESTIMATE 不等于 USER_MEASURED。
- 拟合需可选 SciPy；每数据任务及设置版本共最多 3 次。正向探索另受共享计算和输出上限约束；大网格可能只能容纳较小候选目录。整条数据任务链导出限 128 MiB，超过时可逐版本导出。

- 三理想模型、十二案例、有限目录；没有任意器件设计、通用中文理解或第四求解器。
- 五类本地解释是程序整理当前结果，按钮不调用模型；不能据此声称自由光学问答准确率。
- 目录内最佳不等于全局最优。改判据不改善物理结果；新目录和物理条件须另建计划、核对批准。
- 草稿与父结果分开；采样、参数、指标不同不作同条件增减比较。
- 静态 HTML 无密钥可看。源码默认本地模式；多场景向导支持自己的 DeepSeek 官方 key（deepseek-flash），不支持任意服务商、自定义中转地址或浏览器保存 key。重启服务须重填；同一工作区的页面共用连接。没有公网多租户隔离。
- AI 请求默认累计 20 次，可明确调至最多 100 次；这是次数与单次 token 限制，不是人民币金额上限。动态价格及账户余额以 DeepSeek 官方平台为准。网络失败不自动重试；可能已扣费的请求保留次数，明确确认后可继续新请求，相同未确认请求不重发。
- 完整计算平台为 Linux/Ubuntu WSL，不承诺原生 Windows 一键完整计算。缺 Meep 不称核对通过，NumPy 后备显示实际引擎。
- 轻量 LN 入口不能替代全量数学复核；大体积场证据保留在私有档案。
- 固定模拟用户不是独立真人测试，没有普遍优势证据。仅历史 1 名所有者引导试用。
- 公开、成员、权属与正式提交待所有者集中确认；当前只准备本地资产。
