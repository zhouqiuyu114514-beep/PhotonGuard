# PhotonGuard 技术报告草稿

## 摘要

PhotonGuard是面向光子仿真的本地任务核对与验证工作台。用户可从合成教学卡或已有独立资料开始，无需先写Python。真实DeepSeek负责受约束的资料整理和诊断建议，确定性程序检查来源、未知项、冲突、任务版本和可修改范围；实际Meep/tmm或MPB结果与模型回答分别留证。系统以支持范围内的可复验结果为目标，允许明确拒判。

## 需求与实现

新手容易混淆研究意图、待检脚本参数、仿真运行成功与真实设计达标。工作台将独立任务、程序配方、数值证据和设计目标分别保存。指定模型缺少膜厚等不可替代资料时保留未知；不能从材料名或代码猜成真实参数。教学默认值明示为合成示例。

当前无脚本入口支持空气两侧、正入射Ex、线性无损非色散各向同性单层薄膜；高级入口支持受限多层及只读AST导入。Meep生成实际R/T，独立tmm参考由任务生成；检查覆盖离散采样、能量与物理界、信号和有限数值敏感性。合法修复仍须具体批准及真实复验，上传脚本不任意执行。

真实模型采用JSON草稿与公共反馈，回答不能建立任务锁或改验收阈值。来源引用、数值单位、未知/冲突、解释断言和修改依据分别核验。模型格式合格不等于物理正确。版本、计划与输入变动会使旧确认失效。

## 研究扩展与未决问题

冻结LN连续周期模型已有泵浦上界、低谱至少三计数、高频尾上计数与第三排序根存在区间；云端旧版本证据已核对。连续目标模态的谱投影、偏振/局域性及实际四分支候选覆盖仍未闭合。原1000 μm、20 μm周期与0.1 rad门槛保持，QPM INCONCLUSIVE，设计NOT_EVALUATED。该研究不阻碍薄膜产品开发，也不被产品演示的PASS掩盖。

## 复现、贡献与披露

源码、固定运行环境清单、请求与返回、原失败、测试轨迹、实跑任务锁及数据以来源哈希绑定。Windows入口Start-PhotonGuard.cmd；Linux入口tools/start_photonguard.py。已有环境可使用；锁定安装清单用于新环境，不在用户机器自动安装。默认规则模式，真实AI需显式绑定与凭据，启动不自动请求。

团队成员、实际人工审核及各自贡献尚待真实填写。开发代理参与代码、实验与文档，模拟审批不等于真人审核；没有编造用户满意度、用时或节省比例。Meep、MPB、tmm等为依赖，项目不声称发明Maxwell求解器。依赖版本及来源见THIRD_PARTY.md与runtime锁；本包未包含安装后的依赖二进制。

本稿可用于整理提交材料，尚不是已经公开发布或提交的证明。演示视频是读取保存的实跑证据与实际页面，现场没有新增求解或调用模型。
