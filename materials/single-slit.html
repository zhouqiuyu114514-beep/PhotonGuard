带走与复跑

本文件只读。完整导出 ZIP 同时保留 execution/plan.json、实际数据、CSV 和校验清单。保留整个目录，不用摘要替代原始证据。

在安装了所需工具的 PhotonGuard 源码环境中，对导出计划显式批准一次新计算：

python -m photonguard.experiments.cli run execution/plan.json --out new-run --approve

这条命令将消耗本地计算资源；输出目录须是新目录。AI 密钥不是复跑固定计划的条件。薄膜 Meep 核对需要独立可用的 Meep 环境；缺依赖不能标为核对通过。离线查看无需安装这些工具。
