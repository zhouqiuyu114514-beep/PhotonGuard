# Pro 数值审查执行与候选版本

本阶段在现有隔离副本继续。原工作台运行版本0106f09、旧22案例、全部真实失败和费用账本保留。旧12-worker精度计划仍已耗尽；新研究另有计划、源码和开发委托审阅记录，不延长旧计划或产品修复次数。

阶段A已在本机实际复跑Pro附带的独立审计、连续傅里叶平板参考与体素平均离散平板实验。与Pro数值的最大差分别约1.6e-13及1.4e-12；与旧MPB平板对照最大差约3.97e-9。该机理复现是标量平板实验，不能认证各向异性矩形脊的连续真值。

本地实际读过96个E/H NPZ，逐项复核哈希、形状、坐标、有限性及未裁剪dpwr；未发现负值。旧E-L2-v1指标精确复现。另建16个4×4竞争模式矩阵，E/H分别使用共同物理窗口、周期复数插值，并报告各自尾部。E/H没有拼接或当成功率内积。共用正定权是连续bulk介电张量，明确不等于MPB界面有效张量；旧数据没有D/effective epsilon数组，不能凭|Ei|²份额重建真实逐分量电能。

新候选从backend实际get_dims按晶格轴恢复退化方向，记录实际网格/间距、优化开关、返回根、固定波长材料df/dk及本机构建。后者不是包含材料色散的真实群速度。新不友好网格及退化轴测试使用清楚标记的mock，不执行真实MPB，也不把旧24条记录改成新格式。

界面候选将模式PASS解释为“该模式检查通过”，与长器件相位精度分开；原判断不变。独立research_phase_bounds只给条件包络，当前不存在可认证连续模态区间的后端，任意certified布尔/哈希均不能生成MET/NOT_MET。

后续数值窗口采用Pro建议的6次初始化、最多8次find_k、串行/3600秒、每初始化60秒/求解300秒、每进程min(2GiB,可用一半)、新增持久输出≤64MiB、原工作区1GiB。文件的硬上限进一步收紧为1MiB，保证每进程4MiB预留；低于Pro建议的8MiB。全部额外模型请求0。审批依据为所有者持续开发委托和本次“按pro意见继续推进”，Codex审阅具体计划并记录SIMULATED；不冒充真人UI点击，不能被产品批准接口使用。

材料初始化按本机与官方1.34.0字节一致的张量接口读取epsilon与epsilon_inverse完整实张量；不把get_epsilon可视化标量当epsilon_xx。三Block原表示与slab+cap表示先经连续集合恒等、角点/界面两侧及确定性随机点证明相同。完整张量仅在RAM比较，持久保存摘要和差异分区。

首对为r80半格x平移。物理整体周期平移不改变目标。若E/H身份均明确且任一波长贡献C|delta_n|>0.01rad，已满足“证实离散平移敏感性并量化相位预算”的研究完成条件，提前停止，不为了用完配额继续C2/C3/C4。0.01是研究分账，不是替代原0.1验收。

若首对不足以形成判别，C2严格按tensor差异优先cap、再mesh15、否则tight tolerance；后续仅预注册分支，不根据F是否变好来选。任何失效、超时、身份不清、绑定改变立即记录失败停止，无自动重跑或恢复。

研究worker计算完整四band E/H但只保存指标与原场哈希。新完整场未保存，不能事后重算新场或生成正式产品成功收据。研究结果不改原INCONCLUSIVE/NOT_EVALUATED，不改L=1000、Lambda=20、F目标0.8，不生成绝对效率或严格真误差界。

不新装DOLFINx或COMSOL。下一阶段若需要独立全矢量参考，须匹配连续张量、边界和模式，另形成具体方法/资源方案，不能把PEC标量示例、内部再次调用MPB或两个方法相近当作真值认证。

## 初始化适配修正与缩减窗口

3d5a114冻结窗口首个I0初始化退出-11，原计划与HALTED记录封存。源码核查发现研究适配漏了官方output_epsilon流程的get_epsilon缓冲准备：get_epsilon_tensor写fft_data但不设置curfield，随后get_curfield会读取尚未设置的指针。候选补上原生get_epsilon调用，只为建立缓冲，丢弃可视化标量；mock要求“先准备缓冲、再逐分量读取”，不把mock通过称为真实初始化成功。

显式新源码迁移仅保留I0/I2的四次初始化和C1首对求模态。失败消耗1次初始化及60秒/4MiB预留继续计入，累计初始化最多5次，求模态最多2次；原3600秒绝对截止时间不变。原窗口仍HALTED，没有旧源码重放、自动恢复或次数清零。I1/mesh15、C2/C3/C4在缩减范围内不执行，不将它们列为已排除因素。

## 已实际完成的缩减研究

d65f729执行的四次初始化与两次find_k全部返回0；累计初始化5次含原失败，额外find_k两次、内部本征28次、FDTD/模型调用0。修正后的实际初始化已成功，原失败现场仍保留；研究约58.42秒，峰值worker RSS约320.73MiB，新增持久输出约0.6MiB。

连续等价的原/帽表示在1.55和0.775um的epsilon/epsilon_inverse完整张量比较，分别最大差0.201100849与0.216281236，仅肩/角点区域两个网格单元超过诊断过滤线；平直界面、周期接缝与其余内区未发现超过该线的差异。该证据定位离散表示差异，没有运行帽表示本征值，不能宣称已经量化它对beta的影响或认定全部网格误差都来自这两个单元。

仅沿x平移0.00625um（r80半格），基波delta_n=3.832956875e-5、倍频delta_n=2.335805483e-5；按原1000um长度折算绝对贡献0.310750688/0.189371596rad，相加0.500122284rad，有符号总变化-0.121379092rad。反平移后E/H身份在四band候选内均明确。已证实该离散设置没有恢复物理平移不变性，达到预注册判别目的，提前停止。没有挑选平移后点值改验收；原S与QPM结果全部不变。

实际研究只保存摘要，新完整场及初始化tensor全数组未持久保存；不能事后重算它们。原统计确实保留两个变化单元的区域与最大值，但stride抽样图可能漏孤立单元；后续候选输出改用块最大值与最多32个具体位置/原-新tensor，增加稀疏差异测试。这是记录改善，不回写d65f729实际证据，不捏造旧研究未保存的具体单元坐标。
