# 连续实验会话 v2

浏览器的普通AI入口、案例入口及案例表单使用程序管理的有效事实。旧API与旧完成记录保留兼容，冻结历史评测不回写。

## 可用行为

- 事实按字段保存原始文字、Unicode位置、原文哈希、支持事件、来源及独立物理锁。
- 显式教学、用户表单、用户原文、父结果与数值默认分别标记；模型不能提升自己的来源权限。
- 已知资料不会因模型重复追问而清空。唯一缺项可用短答；多个缺项不猜裸数。
- 等价单位追加证据；不同已知值形成冲突；明确更正、撤回与执行前撤销保留原始事件。迟到版本被拒绝，同事件ID重投幂等。
- 父结果条件仍锁定。修改物理条件必须明确从新任务开始；已有批准、已花计算额度不转移或退款。
- 缺项、冲突、模型结构、来源、范围与服务错误分别呈现。无法理解一句新编辑时不会静默生成旧计划。
- 目标仅影响判定、物理采样一致时，生成新目标报告并复用实际数值；新增求解为0。
- TMM单点目标可读取旧数据中的真实采样点，保留旧数组；新采样点重新计算。涉及Meep的新目标波长仍保守地要求重新核对，不把旧点的独立验证移过去。
- 恢复绑定原记录ID，服务器验证证据并记录结果哈希；不删除后续版本，不退还费用。
- 金额估算仅留开发账本，产品页面显示调用可用性与计算额度。

## 边界

解析器仅覆盖明确字段锚、单位、范围、目录、方向和唯一问题上下文，不是任意中文的语义证明。不能确认的提议停留在待核对状态；单字段短句或参数表可继续，不套用教学物理值。

模型最多一次解释调用；确定性补参通常无需模型。三类已有求解器不扩展到高NA、三维全矢量、Fresnel自由空间等新模型。

结果复用依据现有adapter版本、候选物理参数、数值网格、实际采样与验证级别；修改求解器或适配器的数值语义时必须升级adapter版本。记录中的原始实际数组、检查与来源始终保留。

新R/S首跑的接口混杂与后修区别见research/continuous-session-study/POST_RUN_REVIEW_ZH.md。正式成绩不是当前模型通用能力或真实器件保证。
