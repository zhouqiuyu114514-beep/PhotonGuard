# PhotonGuard 新手入口与真实模型迭代

PhotonGuard把一项明确的光子仿真任务、程序中的设置和实际计算证据放在一起核对。目前无脚本入口支持一维、空气两侧、正入射、线性无损非色散各向同性的单层薄膜。目标是让新手能看懂自己算了什么，以及结果的适用范围。

首页可直接选择“开始薄膜教学示例”，或粘贴“我的模型资料”。教学卡有版本、来源和假设；实际模型缺失的参数保留未知。生成的摘要包括材料、厚度、波段、采样和模板约定。用户确认摘要后，才进入既有任务锁和最多8次FDTD的检查。修复仍需另行确认具体修改。

修改资料会撤销旧确认；未保存时请先选择“保存并整理资料”，或点击“资料暂缺，保存暂停”。暂停会保存编辑框里的当前文字，刷新页面后恢复仍可继续；恢复后需重新核对摘要。未保存文字在本标签页临时备份，刷新或切换后可选择恢复；其他页面已保存新版本时先核对差异。关闭标签页、清理浏览数据前请保存或下载。网络响应中断时先读取最新状态，不自动重发收费操作。

真实DeepSeek可整理已保存的原文，每次最多两次请求；诊断读取已有数值检查和源码位置。模型没有任务锁、改阈值或直接执行补丁的权限。回答中的未知、冲突、引用、动作和说明分别检查。没有合格建议时保留原回答和原因，不用规则伪装成AI。

新手入口已用两个合成薄膜完成实际执行：41点和31点均通过限定检查。31点案例的下载包在新目录复跑，光谱数值完全一致。这是同一安装环境中的复跑，不是跨机器独立复现；操作由开发代理模拟，不计入真人试用。

结果分开说明计算执行、数值检查、设计目标和证据来源。曲线来自具体实际运行。可下载报告、CSV、原始记录、任务锁和规范化复跑配置；导出命令标明尚未执行，不声称修改了原Python脚本。

铌酸锂波导仍在独立实验分支。实际器件必须有独立资料；另开合成教学例会建立新案例。原固定长器件的Mode PASS、QPM INCONCLUSIVE、设计NOT_EVALUATED保持不变。

## 三分钟演示

1. 前40秒：展示首页，选择无脚本薄膜教学卡，指出参数来自合成示例。
2. 接下来40秒：打开一个缺少膜厚的指定模型，展示集中缺项清单；演示真实AI整理后的来源与未知字段，不启动求解。
3. 接下来60秒：打开已有薄膜实跑记录，展示R/T曲线、独立参考、数值检查、保存实跑标签及下载包。明确这些是已完成证据的回看。
4. 最后40秒：打开原长器件模态记录，展示Mode PASS与QPM INCONCLUSIVE同时存在。说明没有改长度、制造周期或阈值来制造通过。

## 常见提问

- AI有没有真正参与？有，保存了官方HTTPS请求、原回答、token用量与校验结果；具体次数以本轮交付报告及账本为准。
- AI一定优于规则吗？没有这个结论。按输入整理和诊断分开比较；普通AI与带反馈AI也可能相同，甚至返回错误。
- PASS能证明真实器件正确吗？不能。它只适用于已锁定任务、已测采样和检查范围；连续误差证书和实际器件验证另行处理。
- 模拟用户算真人吗？不算。场景主体标记SIMULATED，浏览器状态机只读任务卡与可见页面；评分器另读真值。属于逻辑职责隔离，不是操作系统安全隔离，也不是独立真人样本。
- 下载后能直接复跑吗？需要相应PhotonGuard与Meep环境；命令和输入已打包；本轮已实际验证一份31点包可以复跑。每次点击导出本身仍不启动计算。

## 启动与来源核对

Windows入口为仓库根目录的Start-PhotonGuard.cmd，自动根据所在目录定位WSL与现有运行环境，不包含固定用户名。Linux入口为tools/start_photonguard.py。首次使用仍需安装项目依赖与Meep环境；启动器不自动安装软件。

已运行服务会核对源码、数据目录与模式，匹配才复用；不匹配会明确退出且保留原服务。默认启动规则模式。真实模式需当前源码绑定、26元增量账本与内存凭据；密钥不保存在仓库、配置、命令参数或日志里。

正式工作区与开发验收、零求解UI评测目录分开。开发验收使用项目所有者继续推进任务的授权和独立有界计划；零求解评测仍禁止新求解。模拟操作不代替收费授权或真人审核。原工作区证据保留。

网络超时没有用量时，该请求保留完整最坏费用占用，原账本保持停止状态。开发端可以把全部占用与累计次数带入同一26元授权内的后续账期，保留原停止账本及其哈希，禁止重发相同请求；这不是退款或增加额度。报告区分收到回复的请求、未决请求和永久占用上界。
