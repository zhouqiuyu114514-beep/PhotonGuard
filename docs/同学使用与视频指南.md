# 同学下载、使用与制作视频

## 一、下载完整文件

本仓库按公共仓库发布，同学拿到链接后即可查看与下载，无需邀请。点击 Code → Download ZIP，右键“全部解压”，建议放到 `C:\PhotonGuard` 一类简短的本地路径。进入后应看到三个 BAT、app、materials 和 README。

## 二、先看成果和分镜

双击 `打开视频素材.html`。两个薄膜结果可以直接用浏览器看，不需要安装WSL、不需要填写Key。报告14页、展示12页、视频流程约4分钟。HTML在GitHub网页上可能显示源码，请下载解压后打开。

`materials/视频制作流程.md`规定每个片段的旁白、画面、数字和来源。所有已保存片段要标注“保存记录”；历史12→1片段标注“教学合成数据 · 0–1000 nm”。不得用鼠标动画把保存记录伪装成当场生成。

拍摄顺序：850/700 nm差异开场 → 保存的自然语言原文与计划 → 850 nm结果 → 修改目标后的700 nm判定 → 历史12→1 → AI、工作台与开源计算分工 → 成果入口。

保存计划和历史AI选择的真实截图在 `materials/视频素材/`。850 nm选择与理由的放大局部已单独提供。详细历史审查日志不在本仓库，若要追溯原始审计请向项目负责人索取，不把局部素材视为完整恢复工作区。

## 三、启动产品录制界面

1. Windows x64电脑未装Ubuntu WSL：双击 `首次准备环境.bat`，输入Y，确认系统安装；提示重启时先重启。之后从开始菜单打开Ubuntu，按提示建立Linux用户名和密码；输入密码时不显示字符是正常现象。
2. 已完成WSL首次设置：双击根目录 `启动工作台.bat`。首次下载依赖可能需要等待，保持窗口和网络，不要重复打开多个启动窗口。
3. 自动打开浏览器后可查看三类任务与案例。真实AI需要在“连接AI”填写自己的Key；录屏不要展示密钥或账户信息。若要使用负责人账户，由负责人自行在本机输入，不能把Key写入仓库、视频或聊天截图。
4. 新运行和已保存主案例是不同记录。若录制新运行，保留当次结果，数字不同就按实际数字表述；制作既定视频无需为重现旧数字再付费运行。
5. 关闭浏览器不会停止后台。结束后双击 `停止工作台.bat`。

## 四、常见问题

| 现象 | 处理 |
|---|---|
| 提示没有WSL或Ubuntu | 运行首次准备环境，重启并完成Ubuntu用户设置 |
| 下载失败、环境未准备 | 检查网络，再运行启动入口，已下载内容会复用 |
| 浏览器拒绝连接 | 先确认启动窗口提示成功；使用窗口显示的地址，端口可能不是8766 |
| 提示源码文件已改变 | 重新下载完整ZIP解压，勿用编辑器批量转换换行或修改app文件 |
| AI账户余额不足或连接失败 | 核对自己账户及Key；只读材料仍可使用 |
| 其他启动失败 | 查看 `app/logs/` 本次日志；发给负责人前检查是否含个人资料，不上传整个data目录 |

## 五、视频交付

MP4、3–5分钟、300MB以内；建议1920×1080、H.264 + AAC。优先队员真人配音，音乐可不加。另交实际用到的配音/音色/音乐来源与授权、剪辑工程、字幕。成片检查数字、音画同步、匿名信息、保存记录标识，最后由负责人决定公开与提交。不要将成片直接提交进源码目录；先交负责人复核。
