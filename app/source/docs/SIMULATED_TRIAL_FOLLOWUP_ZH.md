# AI模拟试用后的流程修复（2026-10-09）

依据同一个AI的模拟走查报告修复实际界面阻塞。原报告为SIMULATED_AI_USER，真人参与数为0；三个视角不是独立样本。

- 工作区满32案时显示容量、提前禁用新建。侧栏可创建和切换案例工作区，最多8区、每区32案。旧案例默认属于原有工作区，不移动、不删除。工作区是同一用户的案例集合，不是安全租户；全局1GiB存储、单求解互斥与模型账本仍共用，不提供新费用额度。
- 新建任务的独立需求输入默认展开并聚焦；空文本不能提交。已有文本可展开修改。
- 暂停页展示具体缺项、原文与来源记录；“查看/补充资料”仅恢复编辑，不确认资料齐备或启动计算。
- 案例下拉列表首先显示短ID，再显示记录类型、名称、日期；可以修改显示名称并标记AI模拟，不支持由此证明真人参与。元数据变更保留独立快照，不修改锁定任务或旧报告。
- 七步任务内只显示本流程的批准含义；三步流程仍明确批准修改会启动最多8次FDTD。规则服务不展示可用真实AI选项，明确新增模型调用0。
- 报告区分工作区案例ID与物理任务ID，为主要检查增加中文指标与阈值解释；页面省略源码base64，原始JSON下载保留全文。源码位置去重，模态归档可直接返回原始案例。
- 运行证据附绝对时间和运行ID；当前页面观察到的完成记录标为“本页面刚完成”，其他为“已保存的运行证据”。统一4组配对、共8次FDTD的计数措辞。

验证：容量与并发门禁、HTTP同源保护、版本归属、锁定任务保全和旧工作区兼容都有离线检查；实际Edge页面验证另有截图与回执。开发浏览器自动定位失败记录保留，不作为真人反馈。

原有科学结论不随本次界面修复改变：模态PASS、QPM INCONCLUSIVE、设计NOT_EVALUATED。谱上界与根存在性证书未改；连续场投影误差及生产选择器绑定仍未完成。旧付费服务绑定与离线评估协议记录继续保留，当前提供规则服务，不为新源码伪造有效付费绑定。
