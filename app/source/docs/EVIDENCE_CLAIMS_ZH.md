# 解释与证据协议 v1

固定证据中的数值、单位、JSON路径和文件哈希由 `evidence_facts.py` 提取。模型仅提出有限的事实引用、比较和假设，`claims.py` 独立核对并确定性渲染。新诊断合同是 `ai-repair-diagnosis-3`，模型不得用自由文字替代这些断言。

事实值与引用路径匹配、单位匹配、比较方向正确才进入已核验说明；空间离散或运行时长原因仅标为假设。局部敏感度通过不能推导全面收敛；源结束后的时长不等于Courant时间步长。空断言不能支撑自动修复提案。

修改合法性、实际复验和解释审计是三个独立字段。含不支持断言但仍有独立、相关的修复依据时，可以提出带审计警告的修复卡；用户必须读警告并明确批准。批准与当前卡哈希绑定，新说明或源码需要重新审阅。无法找到受核验依据时不生成可批准修复。

旧合同返回仍保留，有限模式检查能够识别已有80→160错误和时长/时间步长混淆。其余自由文本标为未核验，不能把未命中已知错误模式当作全部正确。本次历史用户返回另存审计，不修改旧记录或旧批准。

模型传输仍只保存脱敏的结构化返回和HTTP原文哈希；事实表与断言不解除预算、源码、任务、策略或批准绑定。旧任务策略不变；后续不同物理适配器需独立策略。

新增离线回归包含数值、单位、指针、引用、方向、无限外推、假设条件、历史错误和带警告批准边界。开发测试响应/批准为模拟；不能作真实模型效果证据。
