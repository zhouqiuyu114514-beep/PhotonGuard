# PhotonGuard · AI 光学实验工作台

**0.2.0rc9，本地参赛候选版，未公开提交。** 把研究目标变成可核对的下一步：AI 整理条件、引用已有证据、解释取舍并提出计划，开源计算给出实际结果，用户可以继续追问、修改和比较。支持三类受限理想模型、十二个可执行案例，以及双缝、高斯和已知折射率单膜的数据反向分析。定位是可复核的 AI 研究流程，不承诺科研级器件精度。

RC9 将已有能力整合为用户任务：首页用目标、数据或教学开始；结果优先展示，AI 明确选择的主建议与程序导航分别标注。核对一份列明资源的连续计划后，工具依次完成独立教学补采、纳入新观测、联合拟合与结果回执，完成即停止。改变条件使旧计划失效，真实观测仍须用户提供。

当前核心功能按“AI 辅助、用户核对”定型。模型收到来自当前保存计划的可行清单与阻断原因；超限主建议仍保留原选，页面另列程序给出的可行备选，不代替模型选择或扩大资源。讨论超限方案可只读进行。能力分工与已知边界见 [功能范围](docs/RC9_FUNCTION_SCOPE_ZH.md)。

RC8 已有的独立条件核对、部分有效建议、目标/保护项/移动成本取舍和单频校准继续保留。单频对比传递不能当作完整观测核。原始失败与部分可用状态、离线规则、录制回复复核、开发操作者批准和真人使用分别记录。

| 场景 | 能做什么 | 来源与限制 |
|---|---|---|
| 薄膜 | 单层/有界多层目录、实际波长采样、重评 | tmm 快速计算；Meep 可选独立核对，另记额度和结果 |
| 衍射与干涉 | 理想透镜傅里叶焦平面，单/双缝与相位 | LightPipes / 明示的 NumPy 后备；几何周期指标与二维场校准分开 |
| 高斯光束 | 已知束腰、理想薄透镜和屏幕，比较有限焦距 | q 参数/ABCD；半径为 1/e² 强度半径 |

完成态先显示目标、最佳已测候选和真实图。五类本地说明回答为什么选它、为什么未达标、改了什么、是否重算、下一步允许做什么。数字来自保存的实际结果，不是新的模型回答。

## 怎样开始

**只读查看，无需安装：** 打开工作台导出的自包含 `SUMMARY.html`。不需要 Python、Meep 或 API key，不产生请求。这是保存的实际运行，不是实时 AI；不同历史候选包的目录以各包清单为准。

**本地计算：** 验证平台为 Linux/Ubuntu WSL，未承诺原生 Windows 一键完整计算。Python 3.12 下安装最小依赖后，在源码根运行：

```sh
python -m pip install -r release/requirements-fast.txt
PHOTONGUARD_PYTHON="$(command -v python)" bash START_PORTABLE.sh --data my-experiments --port 8766
```

打开 http://127.0.0.1:8766/experiments 。说出目标、导入 CSV，或明确选择教学任务，再核对计划。十二案例和高级研究入口在展开区。启动和浏览不调用模型。NumPy 后备如实标示，不冒充 LightPipes。需要 Meep 时复用完整锁定环境：

```sh
bash runtime/bootstrap.sh
bash START_PORTABLE.sh --data my-experiments --port 8766
```

完整环境下载较大；只看摘要无需执行。`--offline-review` 禁用求解工作进程，仍可整理本地材料；严格只读请打开静态 HTML。源码须保留目录结构，不承诺单独 wheel 带齐研究资源。

**实时 AI：** 在 `/experiments` 右上角点击“连接 AI”，填入自己的 DeepSeek API key，确认账户及请求上限后“验证并连接”。验证只查询官方模型和账户状态，不发送生成请求；之后在实验里同意发送资料即可使用 AI。key 仅保留在本机服务内存，不写入浏览器存储、项目文件或导出包；重启服务需要重新填写。点击“AI 连接设置”可断开或更换 key。详见 [个人 AI 使用说明](release/PERSONAL_AI_ZH.md)。

默认累计上限 20 次，可明确调整至 1–100 次；失败和超时也占次数，断开、换 key、重启均不清零。费用按 DeepSeek 实时价格计费，次数上限不代表金额上限。计算仍须另行批准。同一本机工作区的页面共用连接，本服务只监听回环地址，不是公网多租户服务。候选包不带作者账户；`tools/serve_ai_repair.py` 仍是历史薄膜诊断入口。

## 带走、核验与复跑

界面可下载 HTML、CSV 与完整证据 ZIP。解压某次正向实验的证据 ZIP，显式执行一次新计算（把路径替换为实际解压目录）：

```sh
python -m photonguard.experiments.cli run /path/to/export/execution/plan.json --out rerun-experiment --approve
```

命令新增本地计算，输出目录须新建。固定计划复跑不需要模型密钥。薄膜原计划要求 Meep 时，缺依赖不能声称独立验证通过，不依赖作者开发目录。

## 分析一段干涉数据（可选）

上传后，可以先用自己的话写出已知条件，点“整理条件并建议数值配置”。例如：“双缝透镜焦平面，波长633nm，焦距200mm，两缝等宽20μm且同相，位置是毫米，缝距90到270微米，其余拟合设置给建议。”数字只在对应字段的原文出处通过核对后进入草稿；缺焦距不能借屏幕距离补齐，平面和相位也不能默认。补充缺项会保留已有条件，冲突需明确更正；已批准版本的变化另存新版本，共享旧额度。

幅度、背景、平移范围和损失尺度可由固定的训练点配方建议，标记 NUMERICAL_SUGGESTION，不是实验事实；不利用留出点挑配置、不扩大已有范围。高级参数表仍可展开。拟合后可问“为何保留残差点”“为什么不能采用参数”等问题：AI 选择解释焦点，数值和限制取自当前记录。正向后新目标超出共享输出上限时，先显示预算并明确选择原候选，保持网格、校准和累计额度。

Python 3.12 环境安装 `python -m pip install -r release/requirements-analysis.txt`。未安装 SciPy 时原有实验仍可使用，拟合入口会明确提示缺少依赖。主页可选三份有来源和许可的合成样例，或上传自己的 UTF-8 CSV：两列 `position_mm,intensity_relative`；也接受明确的 μm、m 坐标。最多 2 MiB、20–5000 行，原文件不清洗、不覆盖。

依次核对单位和固定条件 → 保存拟合计划 → 明确批准 → 查看原始点、预测、残差和全部起点 → 确认采用模型估计，补齐缝高及网格 → 另建正向核对 → 在 D02 中另建目标。可导出单个版本或整条数据任务链，包括缺条件和失败版本。导出的拟合记录可复跑：

```sh
python -m photonguard.experiments.inference_cli /path/to/export/fit-execution/request.json --out rerun-fit --approve
```

只支持等宽、相位 0 双缝在理想透镜傅里叶焦平面的一维相对强度。已知波长、焦距、缝宽；仅估计缝距、中心平移、正幅度及背景。没有刻度、缺少绝对尺度、近场或明显失配时暂停相应任务。结果标记为 MODEL_ESTIMATE，不给置信百分比，不证明全局唯一，也不是实测器件验证。每次最多 9 起点、12000 次实际残差评估、60 秒；同一数据任务及其设置版本累计最多 3 次拟合。AI 只给受当前记录约束的下一步建议，不自动批准计算。

## 反向分析与独立教学补采（RC5 起，RC7 扩展）

主页“从数据反推，再决定补测哪里”提供双缝、高斯及单层膜三条有限分析链，旧已知缝宽入口保持原协议与额度。

- 双缝宽距：已知波长、焦距、相位 0 和物理焦平面坐标；可估计缝宽、缝距及观测干扰量。每个量明确选“已知固定”或“待估范围”，已有事实不会自动放开。原话可整理条件；缺少的幅度/背景/中心范围可用训练点配方建议，之后核对批准。
- 参数证据：规划最多 21 个格点、每点两个局部起点。计划保留等距端点，并用已保存的拟合值替换最近内点，避免粗网格完全错过已知最佳区域；完整网格在执行前冻结，没有按结果无限细化。显示分离的离散候选、失败点和最大网格间隔；不是置信区间，单点不等于零误差。
- 补采：用户限定范围、点数、最小步距、曝光稳定和配准误差，比较三个均匀范围、最多三个混合模板及来源明确的基础方案。双缝为 20–201 点，高斯支持少量 z 位置；评分只用最多 12 组已保存合法联合候选、解析预测和局部灵敏度。候选不足时标明局部建议或固定方案；固定点数下扩大范围可能降低缝距精度。每次可选择自己的新 CSV，或明确选择独立教学对象补采。
- 联合数据：最多三份原 CSV，逐份核对条件和尺度；双缝默认各自 A/B，中心仅在明确配准时共享。旧协议保留等数据组平均误差权重；新独立噪声协议需要显式逐点标准差、独立性、来源和采集 ID，不自动把数值尺度当成噪声。新数据进入拟合后不再是独立验证。每个根任务最多 4 次拟合、6 次参数剖面、2 次补采、6 次补采建议和 2 个正向计划，最多预留 300000 次残差调用；新版本不清零。
- 高斯：导入 `z_mm,radius_1e2_um`，可附 `radius_sd_um`；直径列 `diameter_1e2_um` 需明确批准除以 2。已知波长，固定 M²=1、自由传播无途中透镜/截光，直接拟合半径估计束腰大小和全局位置。单平面拒绝唯一估计，短或单侧扫描保留不足提示。用户确认透镜全局位置后按 `waist_z_mm=z0-lens_z` 转换，接回三种焦距的现有正向比较。

所有原始数据和失败版本可整链导出；教学隐藏对象不发给分析 AI，也不混入数据导出。教学与拟合共享理想物理假设，不是独立实物验证。新拟合/剖面仍需可选 SciPy 1.18.1；未安装时保留旧正向功能。固定请求可在 Linux/WSL 显式复跑，无需 API key：

```sh
python -m photonguard.experiments.inverse_cli /path/to/inverse-execution/request.json --out rerun-inverse --approve
```

单层膜导入 `wavelength_nm,reflectance_calibrated`：仅支持已知实折射率、法向入射、无损单层、厚度待估。单波长保留周期和对称多解，在用户给定的 2–9 个可用波长中比较有限候选反射率分歧，批准补测后联合分析。任意亮度不能当校准反射率，`T=1-R` 不算第二份独立证据；不开放折射率、吸收、增益或任意多层反演。照片相位恢复和真实仪器控制未实现。

## RC7：比较基础方案，再选择下一步

基础方案与局部方案并列保存，显示来源、硬约束、每参数预测尺度、采样风险、行程和分段代价。已知教学问题的 ±2 mm 参考只有满足当前约束时可用，不被当成任意实验的最优方案。最多三种公开噪声/亮度假设检查局部排序是否稳定；保守策略允许选择简单基础方案，不能据此声称实际误差保证不劣。旧四例仅追加固定菜单后仍选 medium，旧成绩保持原样。

观测方式可声明点采样、未知平均方式或有来源的校准强度平均核。已知核在物理坐标上实际计算，不对非均匀数组直接做像素滤波。拟合低残差不能排除平均效应与幅度/背景混淆；没有校准资料时可以提出参考扫描、继续有限分析或停止相应判断，不冒充故障确诊。核分支仍是受限强度观测模型，不代表通用相干像差反演。

AI 的下一步建议可以是澄清、比较补采、选择基础方案、检查观测、请求校准、拟合/后续计划、解释或停止。建议绑定当前版本、公开事实及真实结果；程序检查其前置条件，批准与计算不由模型代替。单膜原话入口仅整理现有已知条件与允许波长目录，不增加用户没有的光源。数值方法效果、真实 API 请求、模拟操作与历史真人反馈分别记账。

**离线复用：** [三个无 UI、无 Key 例子](examples/inverse/README.md)分别读取 CSV 和明确计划，输出双缝基础/候选比较、高斯 5 点补采与联合估计、单膜允许波长内的多候选消歧。薄 API 提供 `run`、`followup`、`inspect` 及一个可替换的固定策略示例；保存资源账本与原文件哈希，复跑不会覆盖旧证据。教学参数和噪声种子已公开，不把这些例子计作盲测或新真人试验。

## 贡献、证据与边界

自主实现：可执行案例与目标适配、事实/约束与版本管理、工具调度与同源证据交付。没有训练基础模型，也没有自研 Maxwell 求解器。生成式 AI 参与代码、研究、测试和材料制作，见 [AI 披露](docs/AI_ASSISTANCE_ZH.md) 与 [第三方清单](docs/THIRD_PARTY.md)。

V4 四段真实 AI + 固定模拟用户会话最终完成，R/S 均 2/2；R 两次提前计算被共同边界拒绝，S 为 0。不证明普遍准确率、成本、求解量或真人效率优势。两组都可重评复用；自由解释准确率未测。历史只有 1 名所有者引导试用，不是人群研究。

当前事实和限制见 [CURRENT_FACTS](release/CURRENT_FACTS_ZH.md)、[claims.json](release/claims.json)、[KNOWN_LIMITATIONS](release/KNOWN_LIMITATIONS.md)。LN 只读入口 /research-certificate 是特定固定周期模型的历史排除证书，相位因子不是转换效率。历史主页保存在 [2026-10-10 版本](docs/README_20261010_HISTORICAL.md)，旧成绩不覆盖。
