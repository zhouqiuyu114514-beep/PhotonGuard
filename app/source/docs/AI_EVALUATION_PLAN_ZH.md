## 最小样本与执行顺序

1. 先制作并冻结 2 个新的独立任务包，各有相同支持语法的脚本、用户书面规格和分离的评审答案。
   A：书面规格完整但字段分散（明确 1 微米单位、层 n/厚度、谱段/点数及范围假设），测整理工作量。
   B：规格缺一个关键值并含 n/epsilon 语义冲突，正确结果是保留未知并提出精确澄清，不能从脚本猜答案。
   同时保留现有开发故障作系统运行控制，但不计入 AI 贡献样本。
2. 为每个包先冻结文件 SHA-256、字段答案/未知路径、允许澄清内容、评分规则及预算；看过输出后不得改题或改答案。
   答案不进入任何条件的用户材料、模型请求或脚本变量名。作者与评分人尽量分离，样本不用于调提示。
3. 条件 R：当前完整规则工具（AST、prepare-task、任务确认检查、已有规则建议和中文文档）。
   条件 M：完全相同工具与材料，再加一个受限模型任务整理建议。不得隐藏基线已有检查或故意给它不完整上下文。
4. 每个条件最多 5 分钟、同样的用户资料和预先冻结的澄清答案，最多一轮澄清；模型每包最多一次请求，无重试。
   模型建议必须由人审查，不能自动写锁。尽量用两位操作者交叉平衡先后顺序；仅一位时报告学习效应，不能声称严格盲测。
5. 完整输入字节上限、输出 token 上限、明确模型/版本、提示词、超时和费用上限在调用前冻结。R 记录 token=0；
   M 使用相同任务资料，不添加隐藏答案或额外搜索。两组均可使用同样次数的求解器与文档，不把额外工具预算伪装成模型能力。
6. 先离线验证下面的提案 schema 和拒绝路径，再运行实验。首次 1 次 API 联调已完成，原0.28元/1次授权已消耗；
   本计划不触发额外调用。必须另取得新的明确模型、数据发送、次数和人民币上限授权，历史20元说明不是剩余许可。
   原session与账本保留，不得重置或另选路径绕过原授权；样本不足就报告pilot，禁止补做挑选成功结果。

## 待实现的可审查建议接口

输出仅为提案，例如 `{"proposed_fields":[],"unresolved_fields":[],"questions":[],"evidence_refs":[]}`。
每个 proposed field 必须包含 task 路径、类型化值以及独立用户规格中的明确行号/原文证据；缺失量保持 unresolved。
脚本观察可以用于对照，但不能充当用户的独立意图来源。严禁输出批准状态、task lock、policy、参考数据或 shell/Python 动作。
解析器要拒绝未知键、无效路径、引用不存在的行、冲突重复字段、非有限数、越界长度及自称“已确认”。
引用存在不证明语义蕴含，仍需人工逐字段审核；原规格和原脚本字节保留，待审草稿单独输出。

当前 `diagnose-api` 处理故障动作而非上述录入接口。2026-10-06已新增独立的离线 `requirements_intake.py` export/import 表面，
接收原文、引用和缺项问题，禁止批准/写锁/求解。它没有模型传输；调用前仍需专用有界适配器和新的费用授权。
不能把 task 整理 JSON 冒充已有动作 schema。新开发材料和对照要求见 `research/intent-pilot/INTAKE_EVALUATION_ZH.txt`。

## 记录与判定

每次会话记录 task 包 SHA、条件、操作者匿名编号、顺序、开始/结束、初始/最终草稿、每次人工字段写入/修改、
问题及回答、实际批准字段/锁、退出原因、模型 usage/耗时/估算费用、实际调用账本，以及独立评审结果。

| 指标 | 固定计数方式 |
| --- | --- |
| 人工字段数 | 人手填入或修改的不同语义路径数；另记总编辑次数。按字段计，不按击键或整块 JSON 粘贴次数计 |
| 审核负担 | 需人工查看的建议字段数、审核分钟数；不能把点击批准算成零工作量 |
| 字段正确率 | 最终已填字段中与冻结独立规格一致的比例；应未知却填值计错 |
| 错误确认率 | 错误或无来源字段中被实际批准的数 / 全部被批准字段数；无批准时记 N/A，另记拒绝完成 |
| 危险会话率 | 至少一个错误/无来源字段获批准的会话数 / 全部会话数 |
| 澄清质量 | 是否指出缺失的具体字段，是否避免用脚本或常识补答案；由冻结答案判分 |
| 完成率/耗时 | 限时内完成正确确认的会话比例；安全暂停单独报告，不能从耗时统计删除 |
| 物理复验 | 只对正确且支持范围内的已确认任务运行相同完整 Meep 检查；不能用修复后 PASS 反证原意图正确 |

预先约定：出现错误确认不得用平均省时掩盖；模型低于基线、无差异、拒答和失败都保留。
两题只能检验流程及发现问题，不能证明统计显著提升、泛化能力或独立科研贡献。
后续是否扩大样本取决于观察到的具体未解决问题，而不是挑当前规则能完美解决的案例重新命名为 AI 效果。
