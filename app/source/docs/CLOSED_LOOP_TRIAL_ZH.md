# 十分钟独立用户试用

本试用全部为公开合成教学资料，已有AI草稿不再收费生成。你本人确认任务、批准修复和点击求解；开发模拟审批与本次试用记录分开。无需输入API密钥。

任务：依据独立需求和任务卡CL-v1，核对单膜R/T，找出待检脚本的材料差异并重验。原文：1D，0度，非磁、无损、各向同性、无色散，空气两侧，单膜n=1.7、厚250nm，1350–1650nm含端点35个等波长点。补充建模依据CL-v1明确：1个Meep长度单位=1微米，线性介质、正入射Ex。范围外的真实任务不可据此填写这些值。

1. 打开交付报告中的“用户试用·完整需求·A1”入口（约2分钟）。逐项看原文、AI值、单位和引用；不要再次点击生成模型草稿。发现未知或冲突就先暂停。
2. 核对并确认语义草稿（约2分钟）。阅读CL-v1补充资料，核对执行映射；保留35个等波长实际DFT点，插值为0。勾选仅表示你已核对已有资料，不表示软件替你确定物理假设。保存映射不会运行。
3. 在“只读导入脚本”页点击载入本次试用脚本，再点击只读解析（约1分钟）。查看差异表，说明材料哪里与需求不符。确认并锁定独立任务；锁定不代表脚本通过。
4. 点击真实Meep检查，等实际状态返回，阅读FAIL、曲线及检查项（约1分钟）。不要把能量守恒单独当作材料正确的证明。
5. 请求修复建议，读具体数值变化。你本人勾选批准这一次修改，然后点击Meep重验（约2分钟）。报告说明原脚本未修改，只有规范化配方改变。
6. 阅读PASS报告并下载CSV/证据（约2分钟）。指出实际求解点、修复内容、为什么通过以及限制。再查看“停止场景”任务：缺失资料可保存暂停；冲突不能选边；15度入射不支持。已锁定需求要修改时创建新版本，旧锁和报告保留。

完成后仅反馈：能否不靠逐步口头提示完成；在哪一步停住；哪些文字不明白；是否能解释改了什么和通过的依据。没有完成也保留记录，不以这次试用推断人工时间节省或AI增益。
