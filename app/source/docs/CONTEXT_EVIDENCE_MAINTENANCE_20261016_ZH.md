# 上下文原文证据核对维护

保留0.2.0rc9功能定型。起因：双缝自然表达中的并列宽高、跨句缝距范围和相邻亮纹目标已被AI提取，却因本地关键词解析不能绑定来源而被拒绝。

## 机制变化

规则可完整核对时保持原路径。需要真实AI且原文仍有未解释片段或字段无法绑定时，追加一次独立证据阅读；若两个阅读器中有一方漏字段，再最多追加一次只指定缺漏字段名的独立阅读。该阅读只看到原文、案例字段、当前事实和未解释片段，不看到首次AI的提议值；两次独立提取须在字段和值上相符，再由程序验证引用原文、位置、数值、单位和支持范围。上下文用于解释并列、省略和跨句指代，不替代数值证据。单个值可从并列句中精确定位；只接受原文唯一对应数值。缺失、冲突、非支持条件保留核对；第二次服务失败不自动循环重试。

原文单位回声与规范单位不同但本地已经同字段严格转换时，保留本地来源值并记录拒绝的模型原值，不因模型漏换算丢弃正确事实。不会依据任意比例纠正模型数字。自然说法的兼容性不是单纯扩充关键词；新路径使用两次语义阅读与本地机械核验。该机制是模型一致性加来源检查，不是自然语言语义的形式化证明，两次同模型调用也非统计独立模型。

固定模型约定可由两次阅读一致识别，支持值仍固定为TEM00、M²=1、1/e²强度半径、空气和单透镜；不扩展物理能力。快算限制不能经语义回退变成额外计算授权。每次实际请求都进入连接配额及任务计数，最多两次额外阅读（总共三次请求），用户不必先选本地整理。

## 连续会话入口

实际ZIP旅程暴露第二轮目标更新仍走旧解析。现已将真实AI的连续输入接到同一原文核验机制；目标专属修改保留旧版本完整物理基线及实际候选目录，不能替换成父版本的获选候选条件，也不能因新目标重新生成隐含候选。仅重新评分已有结果；另行安排新候选必须是明确的新计算计划。未解条件不会继续发起无用动作建议。一般连续输入可本地直接识别并用一次AI建议；需要上下文核对时最多三次整理加一次动作建议，仍逐次计费计数，不能绕过用户计算批准。

## 数值设置维护

原用户400μm缝高超出了默认0.4mm孔径窗口的80%。仅对于未被用户指定、未被父结果锁定的数值默认配置，按最大孔径跨度将窗口适配到0.5mm，必要时只在已有256/512网格选项内调整。记录配置变化与依据，撤销时还原；不改变缝宽、缝高、波长、候选范围等物理条件。显式窗口和父结果不能自动覆盖；原物理和输出预算检查继续生效。波长目录不会被误当成几何跨度。

## 验证及边界

同轮开发失败、修复复测和最后实际ZIP旅程分开保留。覆盖双缝、高斯、薄膜的新自然表述，以及原有55条两轮样本和12类反例。专项测试涵盖伪造来源、错单位、不同字段借数、未知/否定/条件句、锁定事实、并列数值、数值配置撤销。准确批次数、费用、回归数和最终交付哈希见本轮进展报告。
