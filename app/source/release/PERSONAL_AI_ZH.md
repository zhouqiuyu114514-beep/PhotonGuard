# 连接自己的实时 AI

适用于 PhotonGuard 0.2.0rc2 的多场景实验页 `/experiments`。先按 README 启动本机工作台；无需开发者目录、Git、作者账户或开发者的费用授权文件。

1. 在 [DeepSeek 官方平台](https://platform.deepseek.com/api_keys) 创建自己的 API key，并确保 API 账户可用。
2. 打开工作台右上角“连接 AI”，粘贴 API Key，确认本工作区的累计请求上限（默认 20 次）及账户计费说明，点击“验证并连接”。
3. 看到连接成功后返回实验，选择教学案例或填写自己的参数，勾选同意发送当前资料，再点击 AI 按钮。计算计划仍需你单独核对和批准。

连接验证使用官方 `GET /models` 和 `GET /user/balance`，检查 `deepseek-flash` 和账户可用状态，不生成内容，不发送实验资料。没有后台自动对话或自动重试。首次验证失败可按提示手动重试。

## key 和连接

- key 只在本机浏览器提交与服务进程内存中使用，再通过 HTTPS 连接 DeepSeek 官方接口。表单提交后清空；不写入浏览器存储、实验、日志或导出包。
- 关闭网页不会断开正在运行的服务；再次打开仍可继续。关闭或重启服务后 key 丢弃，需重新填写。这不是操作系统级安全擦除或对本机恶意软件的防护承诺。
- “AI 连接设置”支持断开、重新连接、换 key。失败的换 key 不替换原有有效连接；执行中的 AI 请求结束后才能切换或断开。
- 断开个人连接不会回退使用作者账户。原实验与本地计算功能保留。
- 同一本机服务的浏览器页面共用连接。只支持 `127.0.0.1`，不面向公共网站、多用户共享服务器或中转服务。

## 次数、费用和失败

请求计数保存在工作区 `ai-binding/quota.json`，不包含 key。上限累计计算，默认 20 次，可明确改为 1–100 次；换 key、断开、重启都不重置。不要删除额度文件来处理失败；保留审计记录。每次输出最多 4096 token，输入请求最多 120000 字节，按 131072 输入 token 预留。

次数上限不是人民币上限。费用由 DeepSeek 实时计费，界面不显示推算的已用金额，账户费用在官方平台查询。验证接口不发起模型生成。

生成超时、网络断开、用量缺失或回复不完整时暂停连接，保留本次次数与最大 token 占用，不自动退款或重发。核对已有实验及官方账单后，可在设置里勾选“保留该次额度并继续”，重新验证 key。之后允许新的请求；相同内容的未确认请求被拦截。超过 100 次累计上限的长期额度管理尚未开放。

如果提示 key 无效，检查是否完整粘贴以及是否已撤销；账户不可调用则在官方平台处理；网络错误先检查本机网络。连接成功只是说明账户与模型可用，不保证每次模型理解正确，参数来源、实际计算和目标达标仍分别核对。

## 验证范围

2026-10-12 自动化操作者使用所有者已授权的真实 key，在独立空工作区完成验证、2 次真实模型调用、1 个双缝教学实验的实际计算、结果解释、导出与断开。沿用所有者原财务账本；保守高峰估算增量约 ¥0.013674，不是官方账单。另有浏览器连接/无效 key/重载/断开/手机布局检查，以及异常、安全和回归测试。没有新增真人测试，不把自动化试用当作外部用户已验收。
