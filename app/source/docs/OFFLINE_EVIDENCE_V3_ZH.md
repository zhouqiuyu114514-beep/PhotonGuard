# 离线证据记录与评测推进

本副本在2026-10-06已冻结真实批次源码的基础上独立开发。现有界面、演示记录、原始收据和账本没有迁移或改动。这是离线候选版本，不是新付费批次的启动包。

## 改动

- 响应检查分别返回受控代码：类型/空响应/超长、JSON语法、重复键、非有限数、深度、Unicode、脱敏检查，以及语义合同拒绝。
- 错误消息不含解析器原始异常、字段名、响应片段或密钥。JSON格式错误仅记录行列和是否存在代码围栏。
- 对可解析的返回保留递归脱敏后的JSON结构，包括语义校验失败的返回。十进制字面量转为文本，保留精确值。
- 格式错误、超长、深度越界等正文整体省略，仅保留哈希及长度；不尝试修复代码围栏、重复键或填默认值。
- `REDACTION_CHECK_REJECTED`表示脱敏检查改变了内容，可能包括保守省略，不证明发生秘密泄露。脱敏覆盖既有秘密字段、字段名、sk-/Bearer形状、Unicode转义、内层JSON和明文秘密赋值；不承诺识别任意编码或无标记秘密。
- 脱敏结构不是原始答案。`body_is_original_response=false`明确禁止将其当成原始文本的精确重放或完整原始语义评分证据。格式被拒绝的任务仍计入统计。
- 分母包含所有计划任务，分别统计待审核、被拒绝、传输停止和未执行；拒绝与未执行不能合并。旧收据缺少诊断时明确标为`LEGACY_UNSPECIFIED`，不补造旧响应。
- 工具审阅候选和最终返回均记录为独立提交，保存各自哈希、长度和可安全保留的脱敏结构；提交数量与最终任务数量分别统计，不以成功导入筛选提交。

## 离线使用

在Ubuntu终端进入独立副本：

```sh
cd /home/zhou/projects/PhotonGuard-offline-evidence-v3-20261006
/home/zhou/projects/PhotonGuard/.runtime/run-python -B tools/run_offline_comparison.py --simulate --output local-validation/my-new-offline-observation
```

输出目录必须不存在，避免覆盖已有观察。该入口只有规则模拟与只读旧收据统计模式，不读取密钥、不调用真实模型、不执行求解器。A0/A1使用同一份公开合成输入和同一工具实现；缺项/冲突案例缺少膜厚且膜层折射率相互矛盾。模拟不是AI，R0和人工成本仍缺。

新副本中的旧真实启动器仍保留历史代码；由于源码哈希和Git提交不匹配其冻结绑定，不能启动旧批准批次。不要更新它的哈希、删除会话、重置账本或把旧额度转换为新批次授权。

后续真实评测需要为新版本准备独立方案、版本绑定及新账本，并根据当轮明确批准启动。任何失败输出都保留在结果分母；安全保留限制单独说明，不能用脱敏结构宣称原始证据齐全。
