## 算法与误差包围

1. 从[P2]^2加(-y,x)乘齐次P2构造15维向量空间。边上积分采用移位Legendre矩，内部采用两个分量对1、x、y的矩。对15×15有理矩矩阵独立消元求逆。P3用十个有理节点的单项式Vandermonde矩阵求逆，不调用旧基函数构造器。
2. 周期节点、每条边的双侧方向、共享自由度和精确总面积独立核对。边矩反向因子为(-,+,-)，纵向P3交换两边节点。补充检查把所有12800三角形逐项对应到81×81单调张量网格的两半矩形，核查域端点与所有材料/core分割线，从而排除网格覆盖洞与重叠。
3. 所有binary64输入解码为精确有理数。算术端点用Python任意精度整数表示为整数/2^96；加减和求和精确，乘除每次分别向下/向上整除。NumPy只承载对象数组，不借助BLAS做这些积分。π由独立44项Machin交错级数包围，再向外投影到同一有理格点。
4. 在协变Piola映射下重建六个E/H多项式，独立组合Maxwell旋度作用。全三角形二次型使用三次Bernstein表示，参考质量矩为
   `G_ab = multinomial(3,a)*multinomial(3,b)/(56*multinomial(6,a+b))`。
   该式来自 `∫_T λ^α = det(J)*Π α_i!/(|α|+2)!`，并有逐项有理单项式矩回归。
5. outer中央盒与原像素格均独立有理裁剪，裁剪多边形扇形三角剖分后用上述重心矩积分。未调用Green边界公式。像素分片总面积对每个原三角形精确等于1/2；E/H采用同一个原记录整体相位。
6. 从新M、N、残差形成真Rayleigh商与保守残差；独立传播Temple跨越、统一谱隙、投影误差、HF单调性、三个筛选锥界、记录距离与F包络。平方根采用整数开方的160位有理包围。

有限元定义参考：[DefElement的一类Nédélec单元](https://defelement.org/elements/nedelec1.html)。Bernstein单纯形积分背景参考：[Kirby的一阶微分复形有限元算法](https://bpb-us-w2.wpmucdn.com/sites.baylor.edu/dist/6/32/files/2015/01/ssec-1zn3ii2.pdf)。本实现的具体矩公式和校验以源码及精确回归为准。

## 依赖与边界

第二实现没有导入旧strict_high_order_field、record_field_distance或R/C算术。仍依赖原共同自伴域、谱切口1.283/1.299对应的上下计数、扰动Lipschitz命题，以及泵浦n<41/20比较定理。这些上游空间计数/BLAS包围没有在此另写第三实现，因此不称外部形式化证明。

实际执行限额：24个局部单元、最多两次全域遍历、1200秒、1 GiB内存、64 MiB结果。STARTED和结果不可覆盖。普通单元测试用解析合成多项式，不计作原场的额外积分。拒绝检查区分矩/拓扑/坐标/材料错误、输入字节绑定失败、端点次序错误；对H单独调相的实际输入采用冻结提议哈希拒绝，没有冒充重新计算其全域残差。
