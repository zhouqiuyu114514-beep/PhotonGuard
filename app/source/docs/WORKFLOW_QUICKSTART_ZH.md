# PhotonGuard 图形工作流增量原型 · 2026-10-06

这是可审阅的本机浏览器原型。它在原有只读证据查看器旁边增加了实际操作流程。
默认 NO AI，不连接付费模型。源码与原有数值策略、旧证据分开保存。

## 你现在可以做什么

先选“完整合成教学演示”，按一个主按钮一步一步走：

1. 阅读背景、要解决的问题、自己承担的角色，以及独立资料的出处
2. 核对任务卡中已有的物理要求；不从待检代码反推需求
3. 只读导入随演示提供的窄范围 Meep 脚本，查看源码行号及差异
4. 明确确认任务，创建新的任务锁
5. 启动真实 Meep 检查，得到真实运行状态、检查结果与41个采样点
6. 生成单项规则建议，阅读原值、新值、后果，明确批准
7. 对新配方再次运行完整的真实 Meep 检查，比较曲线并下载证据

演示的目标已明确给出：核对单层薄膜的 R/T 与独立任务是否一致。
任务卡写 n=2，脚本写 epsilon=2，因此该模型的实际折射率约为1.414。
建议恢复 epsilon=4 后复验。演示公开揭示这些信息，不是盲测，也不是用户真实器件。
程序保留原始脚本；修复只作用于它提取出的规范化配方。

“我的资料核对”入口不提供自动自然语言提取。先整理已有记录，再用中文单层表单填写已有参数，或从高级入口导入原生 task JSON，
然后导入受支持的脚本。未知值保留 null。你不需要为了推进界面去计算或猜测答案。
选择“资料没有/暂不知道”会保存当前状态并暂停，不会自动补值、联系他人或启动求解。

## 启动

在已经安装官方 Meep 运行时的 Linux 项目目录中：

```sh
.runtime/run-python -m photonguard.workflow --data workflow-data --port 8766
```

或执行：

```sh
bash START_WORKFLOW.sh
```

在同一台运行机器的浏览器打开 http://127.0.0.1:8766/ 。
只有运行此命令的机器可以使用该回环服务；这不是公开网站。
如果复制到新机器，请先按 `runtime/README.md` 安装原锁定官方运行时。
不要安装 PyPI 上无关的 `meep` 包。
交付证据包是 dot 云端已经完成的历史记录，不是你机器刚执行的结果；
默认新工作区为空，只有明确点击运行才产生本机新记录。

Windows 用户可在已有 WSL 的 Linux 项目副本内执行同一个命令，然后尝试本机浏览器。
也提供 `START_WORKFLOW.ps1`，需明确传入新审阅目录的 WSL 路径；参数例子见 `docs/LOCAL_CODEX_WORKFLOW_HANDOFF_ZH.txt`。
本次只验证 dot 云端 Linux；没有替你启动或验证 Windows/WSL，不假定你本地已应用此增量。
请将它放在新目录审阅，不覆盖自己正在使用的源码和旧报告。

旧证据查看器仍可用：

```sh
.runtime/run-python -m photonguard ui --root . --port 8765
```

## 数据与确认

- 每个任务由服务端产生随机目录，浏览器不能指定写入路径或命令
- 背景、草稿、导入与修复都有新快照；确认后拒绝修改任务，不覆盖已有锁
- 报告和原始通量按独立运行编号保存；SHA-256 校验后才能用于建议
- 任务确认不等于检查通过；修复批准也不等于 PASS
- 重复点击和旧页面操作会被版本检查拒绝；同一工作区最多一个求解作业
- 运行状态可刷新恢复。停止网页服务不等于取消已启动的求解作业
- 本版没有已经验证安全的中途取消。工作进程使用原有四组配对与单组时限，完成后保留回执
- 源码模板之外的 Python 会明确拒绝，不会执行上传的脚本或模型代码

## 目前的边界

只支持1D z方向、Ex正入射、空气两侧、线性无损无色散各向同性非磁薄膜。
原生配方按频率等间隔采样，所以换成波长后不是等间隔。
实验性的14字段公共语义接口与这一流程隔离；没有把其“等波长”要求暗中接入原生求解器。
不支持一般 Meep/2D/LNOI 非线性仿真，也没有证明 AI 带来增益。

图形入口没有 API key 输入框、付费 API 路径或自动配额重置。
现有模型试验12/12请求已经用尽；新模型接入需要新的明确授权和独立配置。
本次新增验证的模型调用数为0。

PASS 只覆盖记录的离散频点、假设与固定开发容差。
能量守恒不是充分条件；两档设置接近不是渐近收敛证明。
修复后的 PASS 归属于新规范化配方，不表示原始脚本及其后处理通过。

- 因此没有声称浏览器端到端视觉验收通过，也没有交付伪造截图

应用层的哈希与只追加快照可检查意外改动，不能防止拥有同机文件管理权限的人篡改。
