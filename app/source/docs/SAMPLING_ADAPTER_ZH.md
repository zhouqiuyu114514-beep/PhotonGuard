# 等波长直接求解适配 v1

原始需求不变：在包含端点的等距波长 λᵢ=λmin+i(λmax−λmin)/(N−1) 上求 R/T。执行列表为 fᵢ=1/λᵢ，按频率升序排列；因此报告中波长顺序递减，但点仍等波长。所有点均由 Meep 的显式频率列表 DFT 通量监视器直接累积。没有插值，不声称时间步进为每个波长单独运行：一次宽带FDTD同时积累所有指定频点。

官方接口依据：[Meep Python add_flux](https://meep.readthedocs.io/en/stable/Python_User_Interface/#flux-spectra)。官方文档明确支持任意间距的频率数组/列表。实际 Linux Meep 1.34.0 验证记录随交付保存。

脚本仍只读 AST 解析。新增仅允许3至201个正、有限、严格递增的常量或有限数值表达式组成的显式列表；四个监视器必须同表，源频带必须符合端点。AST对象列表仍限制8项；所有节点、深度、出处预算继续有效。没有 import/exec/eval 动态执行。不同脚本网格或旧等频率网格无法直接对接等波长任务，必须停止；没有默认覆盖。

人工确认：先审阅14项语义字段，再提供有独立出处的1微米尺度、线性及Ex约定，明确审阅单位/双精度映射及采样。保存映射只生成待锁定草稿，不批准任务或启动求解。之后只读导入脚本，再由用户确认锁定任务；修复和运行分别需要显式操作。未知、冲突、超范围不得确认。更改已锁定需求须派生新版本，记录父版本与理由，旧锁/运行不覆盖。

报告列出实际频率和波长清单。圆点代表实际求解点，连接线只为阅读，不代表额外求解或插值。开发容差不变：R/T与独立tmm绝对偏差≤0.01，网格/时间/PML敏感性≤0.005；仅验证该模型、离散点和测试设置，不证明连续全波段正确或渐近收敛。
