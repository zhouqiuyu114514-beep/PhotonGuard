## 范围

## 修复
- 自然语言 nH/nL、中文折射率、四分之一波设计波长、有限层数目录及显式计算波长，直接从原文绑定；支持 nm/微米换算、表格单位和已观察到的口语语序。
- AI 把相同值放错命名空间或把层数目录放入单值字段时，仅凭原文中独立核对的同字段事实修复。不得借用其他字段的数值，不得凭模型补参数。缺项和冲突仍需询问。
- “只做快速计算/不做 Meep”成为可追溯条件，实际计划的 max_fdtd 与 max_meep_validations 均为 0，后续目标修改保留该限制。
- 显式采样列表替代默认扫描网格；不再把未使用的默认扫描范围显示为有效条件。
- 后续修改目标时给 AI 提供当前已验证结果；目标位于已有采样点时可重新评分，材料、膜厚、旧结果保持不变，不新增求解。

## 回归与边界
最终全量回归记录在本地 regression-final.log；最终准确数字见交付进展报告。测试包含禁止越权开启 Meep、同字段来源绑定、条件假设不转事实、原始数值不被模型旧值覆盖。旧 UI 按钮断言由“真实AI诊断”同步为上一版已交付的“AI 问题分析”，并非删除产品检验。

有限理想薄膜教学模型；不承诺任意中文表达均能识别。显式列表必须完整保留，不能以默认网格近似取代。余额不足时不自动重试，已有计划和结果可离线继续。所有者的原失败记录、原文和事件历史保留；恢复时只重新解释其原文，不由开发者手填参数。
