# 长器件相位精度的有限开发研究

这是独立的公开合成数值研究，仍在既有隔离开发副本推进；不是重放已完成的用户修复卡，也不放宽产品每任务一次修复的限制。

## 先复算，再限定运行

`photonguard/mode_precision.py`将两个波长的基础/加密/加大域有效折射率差分别传播到1000 μm器件相位。分别保留有符号变化、绝对贡献及原验证器逐波长取最大值后的保守敏感度估计。即使两个波长恰好抵消，也不会将抵消后的较小值替换原验收指标。网格差不是真误差界，不由两档数据宣称收敛阶。

`tools/study_mode_precision.py --plan`先验证原始场身份、哈希、独立任务及QPM结果，再冻结两份新数值种子64/80的研究任务。每份仍是同一物理截面和两个波长的基础/加密/加大域六项真实检查。旧物理需求和QPM目标哈希保留，数值种子、出处和新任务哈希显式记录。

计划累计最多12个串行MPB worker、3600秒，单进程仍300秒、2 GiB且不超过可用内存一半；保留原32 MiB单文件上限。两份输出保守估计合计约805.25 MiB，研究目录最多1 GiB，运行前和逐份检查磁盘余量。没有扩展到新几何、波长扫描或绝对效率。

所有者已委托Codex处理普通开发修复与复验。Codex审阅冻结计划的确切哈希，记录SIMULATED开发确认、委托依据、源码和资源，再用`--execute --approve-plan-sha256 <确切哈希>`启动。模型不参与审批，也没有模型调用入口。没有自动重试或中断续跑。

## 停止规则

- 固定0.1 rad相位敏感度检查通过后停止，不为了凑数继续80档。
- 模态身份、根/边界或其他模态检查不通过时停止，不自动切换到更漂亮的模态。
- 后一档与前一档额外核对实际场重叠及竞争模态；带号不作为身份。
- 资源耗尽、求解失败或中断时保留证据，不更改物理任务、阈值或费用账本。
- 两档完成仍精度不足时，如实报告范围内未达到精度，不从较好结果中事后挑选PASS。

旧32→48真实AI卡片、原始拒绝、原SIMULATED修复批准和QPM INCONCLUSIVE结果继续保留。新研究能说明数值敏感性，不能冒充AI提出了新的建议或证明AI优于规则。

研究完整证据写入`local-validation/mode-precision-study-20261007/`。结果以实际summary.json为准，本文不预先承诺精度通过或器件设计达标。研究与页面改进均不新增API费用。
