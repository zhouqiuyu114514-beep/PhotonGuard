# 多场景光学实验工作台（研究原型）

入口为本机服务的 `/experiments`。旧薄膜核对入口和只读铌酸锂研究档案保留。

## 可以做什么

本地可执行案例库包含 F01–F04、D01–D04、G01–G04 共十二例。同一份版本化案例同时供界面选择与 AI 检索。可明确选用教学参数，或填写自己的参数；自己的束腰位置等事实缺失时不会采用教学默认值。已有结果预览标为“已有计算预览”，改变参数后必须新建计划并重新计算。

双缝案例可依据目标条纹周期与用户给定的缝距范围，按解析关系提出少量候选，再实际做二维 FFT；解析提议不当成场计算结果。完成后可从选中候选建立相位探索，保持实际选中几何。同一配方细化最多两个阶段，共用累计快速计算、FDTD 与输出额度；失败尝试保留，不重新领取额度。切换配方必须显式建立新探索，原版修订的目录保护继续生效。恢复来源版本直接读取带哈希的旧结果，不重新求解。

案例规划缺少资料时，补充后仍走同一案例入口。后续探索即使首次规划失败，也保留来源结果哈希、已选物理条件与累计额度；重新规划不能变成没有来源的新任务。原版的候选目录修订不能切换案例入口来绕过约束。运行结果和输出用量一并结算后再对外提供完成状态。

案例配方和中文步骤由项目编写；上游 tmm 与 LightPipes 的例子仅用于选题及工具背景。特别是 LightPipes Young 示例使用 Fresnel 传播，本产品的双缝仍限定为理想薄透镜傅里叶焦平面，不宣称复现自由空间示例。

- 薄膜：空气两侧、正入射、无损无色散的1–8层结构；快速比较实际采样光谱，对最多2个入围候选各执行完整8次Meep数值检查。
- 衍射：均匀相干照明的单缝、双缝，理想透镜傅里叶焦平面的二维标量场和中心截线；不同候选采用共同物理强度色标。
- 高斯光束：已知束腰半径与位置的理想TEM00光束，空气、一片理想薄透镜，比较有限焦距目录中的屏幕1/e²强度半径。

教学卡须明确点击。指定资料不填未知物理参数；真实AI只整理数据、选择可引用的结果，不替代求解器产生数值。没有真实AI绑定时，教学卡和完整实验JSON仍可使用，自由文字会提示使用AI或补完整JSON。

## 操作

1. 选择教学卡，或粘贴指定模型资料。
2. 整理目标与有限候选，核对来源、参数锁、模型假设和计算上限。
3. 明确批准当前计划后运行。更改文本会使旧计划失效。
4. 查看实际结果与原始证据，最多叠加6个候选的实际曲线。可在“直接设置下一个目标”表单中另存目标修订，不需要AI调用；物理参数、原候选目录与计算额度保留，运行前仍需核对。相同参数与指标的前后结果自动配对，不把新阈值误写成物理改善。
5. 导出候选CSV，或下载完整证据ZIP；其中有计划、实际结果、检查、候选/曲线CSV与哈希清单。重跑必须显式使用 `--approve`，会再次消耗计算资源。

衍射可比较明确给出的波长目录，预算按其中最短波长核对。每个候选在形成可执行计划之前通过对应工具的支持范围检查；不支持的孔径、焦距、膜厚与目标单位会直接指出，不先启动计算再失败。

## 结果如何理解

运行完成、数值检查通过、达到设计目标是三个不同判断。最优只指实际测试的有限候选；离散波长的最小值/平均值不保证连续波段。单点薄膜目标的独立Meep检查使用包含目标波长的三点小波段，报告会明确它没有覆盖快速扫描的整个波段。

衍射中的条纹周期与首零点由理想模型几何公式计算，同时FFT结果进行解析、功率和双分辨率校准；它们不是从实验照片拟合的实测量。相位参数不等于相位材料设计。同理论的公式/库校准不构成独立科学证书。

## 运行环境与资源

基础依赖为NumPy、tmm；`pip install -e '.[experiments]'` 可安装固定LightPipes版本。缺少LightPipes时衍射会明确标记NumPy FFT后备实现。Meep继续使用项目既有运行环境。

快速工具每工作进程最多60秒、1GiB，普通二维网格为256/512，双分辨率内部校准最多1024。衍射每候选执行2次FFT，计划最多24次场计算，并根据二维原始场与报告大小进一步缩小候选集合；默认本批输出上限64MiB。Meep独立检查沿用既有worker资源政策，并单列实际/预留FDTD次数。收费AI沿用原累计授权账本，不新建额度；交互式任务允许继续补充和修订，每次请求均明确确认、检查累计预算，失败没有自动网络重试。正式冻结评测仍单独执行每题最多3次调用的上限，不把评测上限当作用户整条修订链的永久限制。

## 不在当前范围

真实器件制造保证、非线性/全矢量求解、高NA与像差、任意上传Python执行、一般全局逆向设计、多用户云服务。铌酸锂排除证书仅适用于原定模型与参数窗口，未扩张到此工作台的三个场景。

评测代码与预注册候选题在 `research/multiscene-study`；开发与正式证据按冻结源码分开存放在本地验证目录。AI状态机评测不计为真人试用，保留已有1位项目所有者的引导式试用记录。

案例库的独立冻结方案在 `research/case-library-study`。2026-10-11 首跑为普通工具 Agent 7/12、PhotonGuard 12/12（包括正确停止、正确报告未达标，不能写成12项器件设计均成功）。普通组5项未完成均包含首次动作格式错误；本轮没有直接观察到约束保护挽救错误设计。因此该差异不能单独归因于物理推理或约束算法。两题不提供案例库的补充试验原评分0/2；修正不相关的高斯绘图范围与Meep要求后，同一原始记录离线评分1/2，未重跑收费调用，原分数保留。该极小试验也不足以证明案例库的因果增益。
