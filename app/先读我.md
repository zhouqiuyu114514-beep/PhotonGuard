# PhotonGuard 同学试用版（输入识别维护修正版）

解压整个文件夹，再双击“启动工作台.bat”。不要在压缩包内直接运行。Windows x64，需要 Ubuntu WSL；如未安装，请先运行“首次准备环境.bat”，按提示完成重启与 Ubuntu 首次设置。首次需要联网，之后复用环境。启动成功会打开浏览器，关闭浏览器不删除记录。

点击“连接 AI”，填自己的 DeepSeek API key；密钥不会随包分发。未连接时可使用教学案例和已有计划。账户付费拒绝时不自动重试，可充值后重新连接。此包是干净工作区，不包含制作方的试用记录。

本版增加独立上下文原文证据阅读与数值单位核验，用户可直接选择真实AI整理，不必先本地整理；需要上下文核验时一次整理最多使用三次模型请求。默认衍射计算窗口可适配孔径尺寸，显式指定的数值设置不会自动改变。保留对高斯TEM00、M²=1、1/e²半径定义及其括注、常见条件语序、明确收紧目标等表达的识别，保留薄膜条件识别和快速计算限制；非支持的半径定义或多透镜系统仍需核对，不能被单透镜模型替代。开始计算前仍需核对计划并批准。输入 nH=2.1、nL=1.45，设计波长940 nm，候选总层数2/4/6/8，计算波长780/850/940/1000/1064 nm，940 nm反射率至少80%，只做快速计算、不做Meep，可以直接生成计划，无须逐项重填。

结束使用双击“停止工作台.bat”。再次启动可继续本包 data 中的记录。不要把含自己使用数据的整个文件夹转发他人，转发原始 ZIP 即可。

功能版本保留 0.2.0rc9；维护源码提交以 SOURCE_MANIFEST.json 为准。source/docs/CONTEXT_EVIDENCE_MAINTENANCE_20261016_ZH.md 说明变更和验证边界。源码遵循包内许可证。SOURCE_MANIFEST.json 校验当前公开源码，MANIFEST.json 校验整包文件；历史审阅包中的原始清单仅对应历史材料。

这是理想光学教学与实验规划工作台，不是实际器件性能保证。薄膜快速计算采用TMM，轻量试用环境不含Meep；其他场景的实际后端以界面结果为准。
