# PhotonGuard 使用指南

## 下载与启动

从 https://github.com/zhouqiuyu114514-beep/PhotonGuard 下载完整ZIP并全部解压。Windows x64用户先用“首次准备环境.bat”准备Ubuntu WSL，完成Ubuntu账户设置后，双击“启动工作台.bat”。首次启动需要联网下载依赖，后续复用缓存。使用后运行“停止工作台.bat”。

窗口提供实际访问地址；浏览器拒绝连接时，先查看启动窗口及 app/logs。个人任务在 app/data，更新项目时保留自己的数据备份，不把数据或Key上传到仓库。

## AI连接与次数设置

1. 在工作台点击“连接AI”，输入自己的DeepSeek API Key。
2. 设置“本工作区累计 AI 请求上限（可自行调整）”。新工作区默认20次。
3. 确认个人账户计费说明，点击“验证并连接”。
4. 在任务中允许发送资料，再让AI整理条件。新计算仍需确认计划。

要增加可用次数，重新打开连接窗口，将累计上限提高到大于已使用次数的值，再填写Key连接。例如已经使用20次，把累计上限设为60，剩余40次，不是再增加60次。

已取消100次固定上限，可设置200、1000等正整数。仍需明确填写累计上限；浏览器数字精度范围为1至9007199254740991。次数按实际发出的模型请求统计；一次操作可能调用多次。已发出但失败、超时或状态不明的请求不会自动返还次数。断开、重新连接和重启不会重置累计数。不要删除额度记录来绕过状态核对。

额度记录保存在本机工作区；Key不写入公开仓库，重启后需重新连接。DeepSeek账户余额、服务商限流与本地请求上限是不同约束。费用按实际Token与服务商定价计收，次数不代表固定金额。

## 从单缝示例开始

首页实验台位于示例上方。点击“填入这组示例条件”，再点“开始这个任务”；接入自己的Key并勾选本次资料发送许可后，点击“让 AI 检索案例并按目标规划”。不用先经过本地规则整理，也不用重新填写已有参数。核对三个候选和快速计算计划后，批准运行。完整步骤见[单缝入门示例](单缝入门示例.md)。

## 不连接AI也能看结果

双击根目录“查看示例结果.html”，即可打开单缝曲线与候选结果，也保留历史850 nm薄膜结果。只读查看不发模型请求，也不启动新的计算。工作台中的本地案例可作为自己的任务起点；填写与核对计划后执行。

## 修改源码

app/是带有2026-10-21单缝示例与启动修整的运行包，启动器核对源码哈希。开发请参考 app/source/README.md，在独立开发环境运行。根目录GITHUB_FILES.json是公开项目快照清单；原始运行包和历史研究清单各自保持原有范围。
