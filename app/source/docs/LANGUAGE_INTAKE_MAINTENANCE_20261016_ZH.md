# 高斯任务卡点与语言表述专项维护（2026-10-16）

范围：维持0.2.0rc9、既有三类有限模型。针对用户真实高斯任务卡住进行维护；后续用户授权本轮10元总预算，独立记账，不叠加上轮5元余额。

## 根因与修复

1. TEM00、M²=1、1/e²强度半径中的数字被当成待填写参数。现在对完整、明确的固定模型声明进行识别，包括常见连接词、标题、列表和同句组合；不能仅因一部分词匹配而吞掉其他未知条件。
2. 数值后的“（1/e²强度半径）”被误读成第二个数值。现在只屏蔽明确的该定义括注，保留原文和来源位置；不自行把FWHM、1/e半径或直径换算成1/e²半径。
3. “多个达标时指出光斑最小候选”被误判为假设性物理修改。现在将明确的结果比较要求视作展示要求，既有阈值目标仍有效；“如果达标，焦距改为200mm”仍须确认。
4. “收紧到/为”“放宽到/为”“调整到/为”没有作为明确修改，导致与旧目标虚假冲突。新增这些修改意图，保留事件历史。
5. 光学厚度“波长/4”及“四分之一波长光学厚度对应某波长”的明确写法纳入现有四分之一波膜模型。物理厚度/4及/40不能借用此规则推定设计波长。
6. 反例发现“两片理想薄透镜”曾可能被单片模型接收；已明确拒绝同时使用/串联多片透镜的要求。候选目录里有四片可选透镜不属于此限制。不新增多片模型。

## 真实实验

- 首轮35题，16个两轮任务通过。生成器有4题把四候选任务拆成单候选题，作为无效改写单独保留，不替其补造条件。
- 修复后对31个有效输入用新回复复测，31个两轮任务全部通过。
- 第二批35题，23个两轮任务通过。另4题擅自给范围任务添加候选目录，单独保留为生成器改变题意；其余失败推动对固定模型说明组合语序的修复。
- 最终55条逐字去重的有效表述（含受控人工构造的表格、单位和定义变体）每条两个真实调用，55/55通过。范围覆盖高斯、薄膜及双缝；不是55次不同物理模型。
- 12类反例，第一轮11/12通过，暴露多透镜范围问题；修复后12/12按预期拒绝或询问。模型范围检查可能在调用前拒绝，反例数量不等于API次数。

## 交付边界

未知、冲突、条件假设、非TEM00或非M²=1、FWHM等不兼容定义不能自动改成支持的输入。通过有限语料不表示任意自然语言均可一次通过。用户原始消息和失败事件保留，重解释后仍需用户批准才实际计算。未重做视频/PDF/PPT，未新增物理功能。
