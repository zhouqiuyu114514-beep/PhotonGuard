# 模态与QPM实验分支

本分支复用既有项目、不可变需求、批准与证据原则。旧薄膜 POLICY_HASH 不变；新任务分别绑定 mode-xcut-v1、qpm-shg-phase-v1 的独立策略。未确认的晶轴、几何、温度或组成直接停止，教学例不替代用户器件资料。

MPB 按指定真空波长冻结材料张量，用全矢量 NO_PARITY 固定频率求 k。频率与 k 的输出单位分别是 cycles/um，传播常数 β=2πk 的单位为 rad/um。默认特征场不是1 W归一化；不据此计算转换效率或包含材料色散的群速度。

每个波长保留四个候选模式的完整E/H场，以主偏振、脊区局域性及边界能量选候选，再跨基础、加密、加大超胞三设置比较场重叠和身份唯一性。模式可以改变带号；身份不明则停止。根 tolerance 不当作网格误差。网格差与域差只是被测试设置的敏感度估计，不是真误差的严格上界。

首版公开开发例为600 nm总膜厚、300 nm残余平板、1.4 um宽矩形脊、上方空气和下方人工无色散n=1.44介质。材料仅为Zelmon1997 Table1未掺杂同成分LN、21℃、0.4–5 um。实验室x=晶体Z，y=晶体X，传播z=晶体Y。不是带真实色散SiO2/Si基底的已制造器件。

每个独立执行许可绑定已提交且干净的源码、任务、策略和资源。最多六个串行worker、每个300秒、总1800秒；内存不超过2 GiB且不超过启动时可用内存的一半；模型请求0。失败、超时和中断保留，不自动重试。find_k内部本征问题次数单独记录，不写成FDTD次数。

QPM输入需要实际模态证据清单和身份复核；手填PASS不自动可信。有来源但未由本工具复验的表格可算教学相位因子，但整体标INCONCLUSIVE。F=np.sinc(Δβ L/(2π))²，不能写成绝对效率。对已核验模态，计算可信性PASS与设计目标NOT_MET可同时出现。

制造极化周期、长度与设计阈值属于锁定目标，不作为数值修复。数值敏感度传播到Δβ·L，超过0.1 rad时INCONCLUSIVE；不静默缩短器件。另设短器件教学任务需事先说明，新设计另立任务版本。

材料来源：[Zelmon et al., JOSA B 14, 3319 (1997)](https://doi.org/10.1364/JOSAB.14.003319)。求解器语义：[MPB官方Python接口](https://mpb.readthedocs.io/en/stable/Python_User_Interface/)。实际校准、回归与模式结果保存在本地版本对应的证据目录；通过前不将实验分支写成已验收产品功能。
