# 单缝衍射入门示例

看看缝宽怎样改变中央亮区，同时找到第一暗纹距离符合目标的候选。首页示例会一次填入完整条件。

## 操作步骤

1. 全部解压后，双击“启动工作台.bat”。首次没有Ubuntu WSL时，先运行“首次准备环境.bat”并完成安装提示。
2. 在页面“连接 AI”中填自己的DeepSeek API Key和累计请求上限。可以提高额度，原100次固定限制已取消。
3. 在首页实验台下方点“填入这组示例条件”，原文进入上方输入框；再点“开始这个任务”。填入示例本身不会发送AI请求或运行计算。
4. 勾选允许发送已保存资料，在整理区域点击“让 AI 检索案例并按目标规划”。这就是本示例已验证的真实AI整理入口；无需先点本地规则整理。
5. 检查缝宽候选16、20、24 μm；波长633 nm、焦距200 mm、缝高100 μm；只做快速计算，不运行Meep。目标为中心到第一暗纹6.33±0.05 mm。
6. 勾选批准当前计划，点击执行按钮。三个候选各作两档网格核对，共6次场计算。
7. 查看结果中的中心曲线、二维光强和候选比较；可在图中切换候选。20 μm对应第一暗纹6.3300 mm，保存案例达到目标。
8. 可导出本次记录，或继续描述新的目标；新任务的结果按实际记录保留。

## 示例原文

我想做单缝衍射演示，看看缝宽怎样改变中央亮区。采用均匀相干照明、标量近轴模型，在理想薄透镜的后焦面观察。波长633 nm，透镜焦距200 mm，缝高100 μm，初始缝宽20 μm。只比较缝宽16、20、24 μm，其余物理条件保持不变。希望中心到第一暗纹的距离为6.33 mm，允许偏差0.05 mm。数值输入平面窗口0.4 mm，网格256。只做快速计算，不做Meep。请先整理条件和计划，等我确认后再计算，并显示曲线与二维光强分布。

## 保存结果与数值含义

此前保存记录的三个第一暗纹距离依次为7.9125、6.3300、5.2750 mm。该指标由λf/a给出；曲线和二维图是实际FFT计算。6.33 mm是中心到第一暗纹的单侧距离，中央全宽为它的两倍。

三张二维图使用相同坐标范围及同一线性色标。不同候选没有各自把峰值调成同一亮度。

直接打开根目录“查看示例结果.html”可查看已有结果，不需要API Key。保存运行与自己新运行分别保留来源。
